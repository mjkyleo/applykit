# 04 · 项目经历

> 规则：背景 / 目标 / 行动 / 结果（STAR），突出个人贡献。字段 schema 统一见 `11_模板/字段记录模板.md`。每个项目一组条目。

## 本类目字段清单

- [ ] 项目名称 + 角色 + 时间
- [ ] 项目背景（为什么做，痛点/机会）
- [ ] 项目目标（可衡量）
- [ ] 项目行动（个人贡献：调研→方案→执行→复盘）
- [ ] 项目结果（优先量化）
- [ ] 技术栈 / 工具

## 写作要点

- 行动部分每步标明"我"的角色，不只写团队。
- 不堆砌名词、不虚构参与度、有行动必须有结果。
