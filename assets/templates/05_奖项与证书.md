# 05 · 奖项与证书

> 规则：名称、级别、时间、颁发机构，按含金量排序。字段 schema 统一见 `11_模板/字段记录模板.md`。每个奖项/证书一个条目。

## 本类目字段清单

- [ ] 奖项/证书名称
- [ ] 级别（国家级/省级/校级/行业认证）
- [ ] 获得时间
- [ ] 颁发机构
- [ ] 获奖比例 / 人数（如 Top 1%）
- [ ] 分数 / 等级与有效期（证书）

## 写作要点

- 国家级 > 省级 > 校级，专业相关优先。
- 不写未颁发、已过期或已撤销的奖项，不夸大级别，不凑数。
