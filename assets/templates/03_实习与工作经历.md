# 03 · 实习与工作经历

> 规则：公司 + 岗位 + 时间 + 职责 + 成果，尽量量化。字段 schema 统一见 `11_模板/字段记录模板.md`。每段经历一组条目。

## 本类目字段清单

- [ ] 公司名称（中英文）
- [ ] 岗位名称
- [ ] 起止时间
- [ ] 工作职责（动词开头，2-4 条）
- [ ] 工作成果（量化：提升 X%/覆盖 X 用户/节省 X 成本）
- [ ] 离职原因（如网申要求）

## 写作要点

- 职责动词开头：负责/主导/参与/搭建。
- 成果数字优先；无数据写规模与影响；不把团队成果写成个人成果。
